## 1. Python

**Python** — це мова програмування високого рівня з простим і читабельним синтаксисом. Її часто радять початківцям, але нею користуються й великі компанії.

**Для чого використовують:**
- веб-розробка (фреймворки Django, Flask, FastAPI);
- аналіз даних і машинне навчання (pandas, NumPy, scikit-learn);
- робота зі штучним інтелектом (зокрема виклики API мовних моделей);
- автоматизація рутинних завдань (скрипти).

**Корисні команди:**
```bash
python3 --version          # перевірити версію
python3 script.py          # запустити файл
python3 -m venv .venv      # створити віртуальне середовище
source .venv/bin/activate  # активувати його (macOS/Linux)
pip install requests       # встановити бібліотеку
```

**Віртуальне середовище** (`venv`) — це окрема «папка» з бібліотеками для конкретного проєкту, щоб різні проєкти не заважали один одному.

## 2. Git

**Git** — це система контролю версій. Вона запам'ятовує історію змін у файлах проєкту, тож можна будь-коли повернутися до попередньої версії, побачити, хто й що змінив, і працювати в команді без втрати коду.

**Основні поняття:**
- **репозиторій** (repository) — папка проєкту, за якою стежить Git;
- **коміт** (commit) — збережений «знімок» стану файлів з описом змін;
- **гілка** (branch) — паралельна лінія розробки (основна зазвичай `main`);
- **GitHub / GitLab** — сервіси, де зберігають репозиторії онлайн.

**Корисні команди:**
```bash
git status                 # які файли змінено
git add environment_check.md   # додати файл до наступного коміту
git commit -m "Опис змін"  # зберегти зміни
git log --oneline          # переглянути історію
git push                   # відправити зміни на GitHub
git pull                   # отримати зміни з GitHub
```

## 3. Docker

**Docker** — це інструмент, який «пакує» програму разом з усім потрібним для її роботи (версія мови, бібліотеки, налаштування) в **контейнер**. Такий контейнер однаково запускається на будь-якому комп'ютері — це вирішує проблему «а в мене працює».

**Основні поняття:**
- **образ** (image) — шаблон, з якого створюють контейнер (наприклад, `python:3.12`);
- **контейнер** (container) — запущений екземпляр образу, ізольований від системи;
- **Dockerfile** — текстовий файл з інструкцією, як зібрати образ;
- **Docker Compose** — спосіб запускати кілька контейнерів разом (наприклад, застосунок + база даних).

**Корисні команди:**
```bash
docker --version           # перевірити встановлення
docker run hello-world     # тестовий запуск
docker ps                  # список запущених контейнерів
docker build -t my-app .   # зібрати образ з Dockerfile
docker compose up          # запустити сервіси з docker-compose.yml
```

> ⚠️ На цьому комп'ютері Docker поки **не встановлено**. Для macOS його можна встановити через [Docker Desktop](https://www.docker.com/products/docker-desktop/) або командою `brew install --cask docker`.

## 4. Localhost і тунелі

**Localhost** — це адреса твого власного комп'ютера (`127.0.0.1`). Коли ти запускаєш сервер локально, він доступний за адресою на кшталт `http://localhost:8000`, де `8000` — це **порт** (номер «дверей», через які працює програма).

Наприклад, простий сервер на Python:
```bash
python3 -m http.server 8000
# відкрий у браузері: http://localhost:8000
```

**Проблема:** localhost бачиш лише ти. Інші люди в інтернеті (або сервіси на кшталт вебхуків Telegram-бота) не можуть до нього достукатися.

**Тунель** вирішує це: спеціальна програма створює публічну адресу в інтернеті (наприклад, `https://abc123.ngrok-free.app`) і пересилає всі запити до неї на твій localhost.

**Популярні інструменти для тунелів:**
- **ngrok** — `ngrok http 8000`
- **Cloudflare Tunnel** — `cloudflared tunnel --url http://localhost:8000`
- **localtunnel** — `npx localtunnel --port 8000`

**Коли це корисно:**
- показати свою роботу іншій людині без розгортання на сервері;
- тестувати вебхуки (Telegram, Stripe, GitHub тощо);
- перевірити сайт на телефоні.

> ⚠️ Тунель робить твій локальний сервер доступним для всіх, хто знає адресу. Не відкривай через тунель нічого з паролями чи особистими даними й вимикай тунель після роботи.
